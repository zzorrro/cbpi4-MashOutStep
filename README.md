# cbpi4-MashOutStep

Плагин шага MashOut для CraftBeerPi 4.

## Описание

Автоматизирует этап MashOut (мешаут) в процессе пивоварения. Плагин позволяет:

- Установить целевую температуру для мешаута
- Задать время выдержки
- Автоматически отключить мешалку при старте шага
- Автоматически включить насос для циркуляции с настраиваемой задержкой
- Автоматически выключить насос при завершении шага

Задержка перед включением насоса позволяет дробине устояться на фальшдне перед началом циркуляции.
